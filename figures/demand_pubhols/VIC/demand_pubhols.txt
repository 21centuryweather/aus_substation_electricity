How these simple demand vs time plots were generated:

These plots show the demand over a 24 hour period for each national and state public holiday in Victoria. 
The data is half hourly electricity demand at from multiple distributor companies, at the local substation/suburb spatial scale.

This was generated by using the notebook "/home/565/pv3484/aus_substation_electricity/pia_notebooks/QLD_VIC_data/VIC/demand_publholds.ipynb".

What was used inside the notebook:
"/home/565/pv3484/aus_substation_electricity/data/cleaned_data/VIC" - the path to the cleaned demand csv files for each distributor 
VIC_holidays.py - generate a library of each national and state public holiday to loop through between the years 2004 - 2017 (if available).
metadata.csv - a metadata file in each distributor's folder contains information about the substations. It contains the full substation name and information such as residential fraction, land use, parkland etc.

Plotting:
Each plot has the demand (MW) of the 24 hour period for every year with data available, representing by the lines.
The data is in half-houlry increments, but was converted to hourly for cleaner plotting.
    - Each half hour was grouped by hour
    - The mean of the two time stamps was found and reindexed as an hour

Looping function:
Created to loop through each distributor, to produce the demand vs time plots for each substation. 
The metadata is used to produce the plots with full substation names in titles.

Saving:
Each distributor has it's own folder, with each holiday saved as a multipage pdf file.
Within the pdf file, every substation has it's own plot with the available data plotted as a different coloured line.
